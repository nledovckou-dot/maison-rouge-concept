# Maison Rouge — концепт сайта

Публичное превью: https://nledovckou-dot.github.io/maison-rouge-concept/

Актуальная версия: дневной зал, переход к ночи при прокрутке и погружение луны в бокал с видео Kling.

## Запуск

Сайт статический, сборка не требуется. GitHub Pages публикует корень ветки `main`.

Для локального просмотра сервер должен отдавать этот каталог под `/maison-rouge-concept/`: внутренние ссылки рассчитаны на этот префикс.
